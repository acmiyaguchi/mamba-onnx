# Mamba ONNX CPU Optimization

**Goal**: Demonstrate a 50x speedup of Mamba inference on CPU by replacing the Python loop with a custom AVX2 C++ kernel.

## Project Structure

- `docs/`: Project documentation (Proposal, Design, Tasks).
- `src/`: C++ source code for the custom kernel (to be created).
- `lib/`: Compiled shared libraries (to be created).
- `vendor/`: Context and code archeology from other repositories.
